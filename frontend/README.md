# HackMatch Frontend Prototype

This is the vanilla HTML, CSS, and JavaScript frontend prototype for HackMatch.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Demo behavior

- Hackathon listings and recommendation results currently use fictional sample data.
- Bookmarks and the demo user profile are stored in browser localStorage.
- Sign-in is frontend-only demo mode; it is not real authentication.
- `script.js` contains placeholder API calls for the future Core Java backend at `http://localhost:8080/api`.

Demo credentials in the original v0 package: `priya@college.edu.in` / `password123`. In demo mode, any valid email and a password of at least 8 characters is accepted; no password is sent to a server or stored.
